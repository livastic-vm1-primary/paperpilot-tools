What this changes — and deliberately does not

Structure only

It remaps chosen source columns to Koinly's published header spelling and copies every original source record in its original order. Unmapped input columns remain as clearly named Source: fields; Koinly may ignore extra columns. Text resembling spreadsheet formulas blocks export instead of being executed or quietly modified.

Never invent accounting facts

No automatic UTC conversion, trade side, Total, acquisition price, token identity, cost basis, wallet link or tax treatment. Missing or malformed evidence blocks the entire generated candidate CSV; use vendor docs and a qualified adviser where needed.

Trades may still merge in Koinly

Koinly's separate importer can combine fills sharing Order ID. This mapper itself never merges or deletes rows. Verify the real imported row/event count independently before considering any result accurate.
