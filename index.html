A FEW GOOD QUESTIONS

Before you get started.

Is PaperPilot available to purchase right now?

A tested offline ZIP is ready for a buyer-initiated manual order at 5 native Base USDC. There is no instant card checkout or escrow. Read the order page and email us first to agree licence, private delivery and refund terms; do not send funds beforehand.

Is the invoice software actually offline?

Yes. The downloaded HTML, CSS and JavaScript files run locally in a modern browser. There is no server dependency, tracker, or cloud document storage. Your browser may still need network access for unrelated features.

Does it issue Korean electronic tax invoices?

No. It generates printable document templates, not certified e-tax invoices (전자세금계산서). Check your legal and accounting obligations separately.

Can it convert between currencies?

No. Changing the display currency changes the format and symbol; you must enter the appropriate amount yourself. No live exchange-rate conversion is performed.

What if I need a custom version for my business?

Contact us with your workflow needs for a scoped quote. No chargeable work starts until terms and payment method are mutually agreed.
