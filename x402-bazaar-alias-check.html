What a finding means

When a source-verified group contains two or more keys in info.input.body or info.input.queryParams, a client may edit the wrong one. The safe remediation is to inspect the real handler's priority and publish one canonical example key for each logical parameter. Even equal values are problematic when an agent later edits a shadowed field. No finding means only that declared groups did not collide; it is not a vendor security audit.
