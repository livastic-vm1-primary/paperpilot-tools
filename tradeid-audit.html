This tool is a bounded, deterministic heuristic for the headers Trade ID, Fill ID, Execution ID, Transaction ID, TxID or Order ID (case/punctuation insensitive). It deliberately refuses amount-only data with no ID. Optional amount, asset and date columns improve the warnings. It does not deduplicate, modify or transmit your file.

Interpret carefully

  • Same amount, different IDs: both fills may be legitimate. Never discard one merely because quantity matches.
  • Same ID, different rows: might represent multiple legs, partial fills or an export issue. Inspect source semantics.
  • Exact repeated rows: candidate redundant exports; not proof that a transaction should be removed.
  • Missing IDs: re-export IDs or request them from the source; don't fabricate them.
