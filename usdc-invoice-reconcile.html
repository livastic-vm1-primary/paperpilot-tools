What can be flagged

  • Candidate exact amount, partial/underpaid or overpaid invoices.
  • Repeated chain + transaction hash + log index — review, never silently delete.
  • Same transaction hash, distinct log indices: genuine separate event candidates.
  • Declared wrong network, wrong token (including noncanonical bridged assets) or wrong recipient; zero-address burn/mint and self-to-self transfers must never be counted as independent customer receipts.
  • Missing, invalid, ambiguous, duplicated or unknown invoice references and CSV fields.

Critical boundaries

  • Only Base mainnet 8453 and native Circle USDC contract 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913.
  • Exact 6-decimal integer arithmetic; no floating point or exchange-rate assumptions.
  • All statuses are unverified CSV candidates, including candidate exact matches.
  • Report omits raw transaction hashes, recipient addresses and invoice IDs; local row numbers and candidate amounts can still be commercially sensitive.
  • Never automatically import to ledgers, delete events, initiate refunds or claim tax/accounting assurance.
